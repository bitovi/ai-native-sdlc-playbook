The transition path

From row 1 to row 5

There is no single fixed sequence. The plays are modular and the stages are non-linear. The five steps below are our labels for the rows of the course's dependency graph. The course itself uses rows, not phases, and gives no timeframes.

Row 1: start anywhere

No prerequisites. In practice, the course suggests this order of thinking:

Foundational filesCLAUDE.md and skills
GuardrailsHooks and the feedback loop
Workflow artifactsintent.md and plan mode

Row 2: scale the build and test

Parallel sessions and subagents need CLAUDE.md, and the feedback loop helps. Continuous evals need CLAUDE.md and the feedback loop.

Row 3: design and review

Requirements and design need intent.md and skills. AI in the PR review loop needs evals and subagents, and skills help.

Row 4: CI/CD

CI/CD integration and deployment needs PR review and hooks. The gates must exist before automation speeds anything through them.

Row 5: close the loop

Closing the loop on metrics needs CI/CD and intent.md. Production signals write the next intent.md.

Most organizations sit between the traditional and AI-native ways of working. You can move one stage at a time.

The course's rules for the move

Prompt by hand firstThen make it an org-level slash command. Then trigger it on merge of the previous artifact.
CI/CD: read-only firstStart with read-only judgment steps. Add write steps behind existing gates, then expose deployment through MCP, then tier autonomy by environment.
Start with 2 to 3 parallel sessionsAdd more only while review keeps up.
Auto mode comes laterMake it the default for routine work only once guardrails mature: a tuned CLAUDE.md, skills that encode policy, hooks that block unsafe actions, and a test suite Claude can run.
One policy, one named ownerSkills first target one inconsistently enforced policy.
One metric, one stable baselineStage 6 first targets one metric with a stable rolling baseline.
Legacy tools: linkage firstArtifacts note the record ID, and legacy records carry the commit SHA. Then pick one source of truth per artifact.
